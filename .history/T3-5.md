## New compared to Java 8/11 and Spring Boot 2.x

| Java / Spring | React / TypeScript |
|---|---|
| `HttpSession`, `SecurityContextHolder` | `localStorage` + `useSession()` |
| Servlet filter adding a header | Axios interceptor |
| `@PreAuthorize` on a controller | Route guard: a pathless route around its children |

## Concepts explained during this task

- **Where to keep a token (your question):** BFF > HttpOnly cookie > in memory > sessionStorage = localStorage against script theft. localStorage and sessionStorage are equally exposed; sessionStorage only lasts shorter. HttpOnly cookies can't be read by JavaScript but need CSRF protection (`SameSite=Strict`).
- **Interceptor:** code that runs on every request or response.
- **Pathless route:** adds no URL, only wraps its children.
- **Hiding isn't security:** every role rule in the frontend is only convenience; the backend decides.
