### 6. API changes (your decisions: both "yes")
- **`createdBy` / `updatedBy` in every response:**
  - `CategoryResponse`, `SupplierResponse` and `ProductResponse` end with `createdAt, createdBy, updatedAt, updatedBy`, so each "when" sits next to its "who".
  - The mappers read them from `BaseEntity`.
- **`productCount` on categories:**
  - It counts products **directly** in the category, not in its subcategories, matching the mockup's "Products" column.
  - **List:** one grouped query per page, `ProductRepository.countByCategoryIds(ids)`, a JPQL `GROUP BY` returning an **interface projection** `CategoryProductCount (categoryId, productCount)`. Categories without products are absent from the result and get 0. An empty page skips the query, because `IN ()` is invalid.
  - **Get and update:** the derived query `countByCategoryId(id)`.
  - **Create:** 0 without a query.
  - `CategoryMapper.toResponse(category, productCount)`.
- **Tests:**
  - Controller tests check the new JSON fields.
  - Service tests check counts for get, update and create, the list with a category that has no products, and that an empty page makes no count query.
  - A new repository test runs the grouped query on MySQL.
  - The integration test checks counts and audit fields over HTTP.
- **Docs:** response field lists in the service README, the audit note, and the conventions' example JSON plus a rule that every response ends with the four audit fields.

## Concepts explained during this task

- **Dev proxy vs CORS:** the browser blocks calls from `localhost:5173` to `localhost:8082` unless the server allows it (CORS). A proxy in the Vite dev server forwards `/api` to the backend, so the browser sees only one origin. Later the gateway is the single place for CORS.
- **N+1 avoided for counts:** counting per row would be 1 query for the page + 20 count queries; the grouped query makes it 2 in total.
- **Why money math stays in the backend:** JavaScript numbers are binary floating point like `double` (0.1 + 0.2 ≠ 0.3); only `BigDecimal` gets cents right.
- **Line endings:** Git stores text with LF (`.gitattributes eol=lf`); files written before that rule kept CRLF on disk until they were checked out again.
